# Simulations

## S1: Branching process

Branching parameter m in {0.70, 0.80, 0.90, 0.95, 0.98, 0.99, 1.00}. External drive, 10 ms synaptic kernel, downsampled to 250 Hz, pink noise added, projected to 64 channels via MNE spherical head model.

## S2: Factorial dissociation

Modulated oscillation x(t) = A(t) sin(2 pi f t + phi) + aperiodic noise. Hurst exponent H crossed with noise exponent beta. 50 seeds per cell.

## S3: Distortions

White-noise SNR in {no noise, 20, 10, 0 dB} crossed with epoch length in {30, 60, 120, 300 s}.
