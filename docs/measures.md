# Measures

## DFA exponent

Detrended fluctuation analysis of Hilbert amplitude envelopes in theta (4-8 Hz), alpha (8-13 Hz) and beta (13-30 Hz) bands, conditional on a spectral peak above the aperiodic fit.

## Aperiodic exponent

Spectral parameterisation (1-40 Hz) via FOOOF with knee model disabled. Includes a 30-45 Hz narrowband variant.

## Lempel-Ziv complexity

Median-binarised normalised complexity. Broadband (1-45 Hz) and narrowband (30-45 Hz) variants.

## Higuchi fractal dimension

Computed via `antropy.higuchi_fd` with kmax selected by stability sweep.

## Avalanche kappa index

Power-law fit to avalanche size distributions via maximum likelihood, compared against the reference exponent (Shew et al. 2009).

## Avalanche branching ratio

Mean ratio of events in the next time bin to the current bin within avalanches.
